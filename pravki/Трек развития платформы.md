 На основе полученных замечаний (процентили >100%, подмена статистических понятий, нечитаемые единицы измерения, дрю) возможен следующий трек доработки прототипа. 
 1. Критические исправления Необходимо для приведения логики в соответствие со здравым смыслом. Исправление расчета процентиля: Проблема: Значения >100%. Решение: Изменить формулу расчета перцентиля с rank / N на (rank - 1) / (N - 1). Добавить каппер (min/max) на уровне 99.9%. Результат: Максимальное значение будет ровно 100%. Корректная обработка категориальных переменных: Проблема: Расчет процентилей для пола, типа операции, наличия терапии. Решение: Исключить категориальные и бинарные признаки из блока "Процентиль распределения". Для них достаточно текстовой метки ("Да/Нет") или специальной метрики (например, "Доля в когорте: 15%"). Переименование единиц измерения: Проблема: +0.8 (непонятно чего). Решение: Подписывать везде явно: "+0.8 процентных пункта” для тепловой карты и "Относительный риск 1.12" для факторов. Добавить сноску: "Вклад в изменение абсолютного/относительного риска". 
 2. Статистическая достоверность Переход от "ранжирования" к "клинической калибровке". Смена визуализации когорты: Проблема: Закрашенная область (IQR) без усов и доверительного интервала. Решение: Заменить IQR на 95% доверительный интервал для медианы когорты (узкая область). Добавить опционально Box-Plot для показа разброса данных, чтобы пользователь видел экстремумы. Калибровка модели: Проблема: Выход модели - процентили, а не вероятности. Решение: Перевести выходной слой модели на калиброванные вероятности. Цифра "Риск: 20%" должна соответствовать реальной частоте событий в тестовой выборке. Учет редких событий: Проблема: Значение "выше 0%" для лапаротомии. Решение: Внедрить порог min_count. Если фактор встречается реже 5% в выборке - не выводить его как модифицируемый, показывать предупреждение "Недостаточно данных для оценки влияния". 
 3. UX/UI и прозрачность Повышение доверия к интерфейсу. Детализация метрик: Добавить всплывающие подсказки при наведении на +0.8. Текст: "Абсолютное изменение итоговой вероятности (в процентных пунктах) относительно среднего по когорте". Индикатор калибровки: Добавить в шапку приложения значок "Режим демо" или шкалу "Уровень доверия к цифре". Для сценария если модель не калибрована - показывать цифры серым цветом. Блок "О методе": Создать явный раздел, где четко написано: "Важное предупреждение! Текущая версия платформы - демонстрационный прототип. Она иллюстрирует логику работы алгоритма, но не является медицинским изделием и не предназначена для принятия клинических решений. Все числовые значения, процентили, графики и вероятности следует рассматривать как техническую демонстрацию, а не как валидированные медицинские заключения.".
